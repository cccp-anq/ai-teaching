## 七、升级版 DoD（团队协商确定）

1. 功能可运行，核心流程跑通；
2. 有基本测试，关键路径测试通过（新增用例 + 既有回归用例）；
3. 关键函数和模块有清晰代码注释；
4. 代码已审查：AI 生成代码须经人工审查 diff 后合入，人对最终交付质量负责；
5. **与 Sprint 1 增量集成通过、关键回归测试通过**（新增功能未破坏 Sprint 1 既有功能）；
6. 关于 CI：本仓库当前未搭建流水线（Sprint 1 README 明确「本轮只标准化命令，不创建流水线」），本轮以仓库内 `scripts/Verify.ps1`（Maven test/package、npm ci/typecheck/test/build）全绿作为等价构建证据。

未达到 DoD 的故事标记为「未完成」，不计入 Sprint 增量。
